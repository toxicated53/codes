go to ec2 instance

give name 
select m3.micro 
generate a rsa key pair and give the name to it
allow http and ssh 
launch instance

=====================================================================


ONCE instance is launched take the ip address and type the follwoing command in the terminal 

make the .pem file to read only to yourself

chmod 400 mykey.pem

ssh -i key_name.pem ubuntu@ip_address of ec2 instance

now you will be inside the ec2 instance
